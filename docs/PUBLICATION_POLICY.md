# Publication Policy

## Safe to publish

- README
- 手順書
- パッチ適用スクリプト
- 抽出スクリプト
- レコード一覧
- 自作コード

## Publish only after rights review

- 翻訳済み本文の全文 JSON
- 翻訳済み本文の全文 TXT
- 復号済みヘルプ本文

## Do not publish

- `all.ppp`
- `all.ppp.bak`
- `PQTC.exe`
- ゲームインストール由来の DLL / EXE / OTF / TTF
- 抽出済み全文アセット
- セーブデータなどのローカル実行データ

## Practical recommendation

GitHub には次の形で出すのが無難です。

1. 日本語化プロジェクトの説明
2. 抽出手順
3. 適用スクリプト
4. 対象レコード一覧
5. 権利上の注意
